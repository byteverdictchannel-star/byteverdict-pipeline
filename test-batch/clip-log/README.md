# Clip Log Directory — TB-001 (Test Batch)

Working directory for the ByteVerdict test batch clip log entries.
Each subfolder holds the documentation for one produced clip.

**Standard fields per clip:**
- Clip ID, date produced, related clips
- Source (which outlet, which video ID, timestamps, transcript refs)
- Attribution tier and display text
- Overlays used (filename + tier)
- Export path and specs
- Posted? Which platform, video ID, posting time
- Notes (source gaps, audio status, sensitive-content flags)

**Clips in this batch:**
- `tb001-c2-eby-51st-state.md` — BC Premier Eby "51st state" quote, CNN source
- `tb001-c3b-energy-leverage.md` — Reuters energy-leverage source, ByteVerdict edit
