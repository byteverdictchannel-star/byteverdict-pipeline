2. Re-verify (independently, not by trusting a checkbox): overlay accuracy vs source, sensitive-content screen was actually done, source audio is English or has English captions.
2b. MANDATORY (added 2026-08-28, Leo's directive — do not skip): run `python3 pipeline/tools/watch/scripts/watch.py <source_or_export_path> --detail efficient` and Read every returned frame path. A single vision_analyze frame is not enough for attribution/identity claims — it only samples one instant. Specifically check across the full set of frames, not one frame: (a) does the on-screen outlet watermark/logo match the "Source:" line in the overlay and caption, (b) does any visible nameplate, chyron, or lower-third identify the speaker, and does that match who the caption names and their stated title/role, (c) nothing in the frame set contradicts a factual claim in the caption.
